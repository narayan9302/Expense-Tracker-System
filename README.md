# 💰 Expense Tracker System (C++)

A console-based Expense Tracker built using C++ with Object-Oriented Programming and File Handling.

---

## 🚀 Features

- Add new expenses
- View all expenses
- Delete expenses by ID
- Persistent storage using file handling
- Category-based expense tracking

---

## 🛠️ Technologies Used

- C++
- Object-Oriented Programming (OOP)
- File Handling (ifstream, ofstream)

---

## 📂 Project Structure

Expense-Tracker-System/
│── main.cpp
│── expenses.txt   (auto-created)
│── README.md

---

## ⚙️ How It Works

1. Data is stored in a text file (`expenses.txt`)
2. Each expense is saved in the format:

ID|Title|Amount|Category

3. Program loads data at startup and saves after every operation

---

## ▶️ How to Run

### Compile
g++ main.cpp -o expense

### Run
./expense
